# NextWatch

Cinematic movie search web app UI. Dark theme, glassmorphism, responsive grid.

## Tech Stack
- Vanilla JavaScript
- Vite
- Tailwind CSS

## Setup Instructions

1. **Clone repo:**
   ```bash
   git clone https://github.com/Moshiour45/next-watch.git
   cd next-watch
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## Development
- `index.html`: Main UI structure
- `src/style.css`: Tailwind imports
- `src/main.js`: Main logic entry point (empty, ready for logic)
